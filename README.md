## 🎮 What is StockQuest?

StockQuest is a forest-adventure stock portfolio game for non-finance beginners. Players pick a real stock as their avatar, race through a dynamic forest maze, dodge market risks, collect treasure chests, and make live investment decisions powered by Claude AI — all while learning how markets actually work.

---

## 🗺️ App Flow

```
/ (About) → /register or /login → /home (Market) → /setup (Pick Stock) → /game (Race!) → /results
```

---

## ✨ Features

- **🌲 Forest Runner Game** — 2-minute endless runner on an 1100×550 canvas with parallax forest backgrounds, tree stump obstacles, treasure chests, start/finish flags
- **📊 Market Overview** — Live stock table with sector filters, sparkline trends, sortable columns, and hover tooltips for every financial term
- **🧠 AI Branching Storyline** — Each market event pauses the game and presents 3 unique choices generated by Claude 3.5 Haiku, tailored to your stock and event
- **🏃 Avatar System** — Company ticker initial as avatar face, floating nametag, sector-color-coded
- **🎯 Smart Stock Picker** — Filters by sector (Tech / Finance / Energy / Manufacturing), risk level, and investment amount — auto-picks the highest return rate match
- **🌅 Sky→Forest Animation** — Setup page descends from sky to forest floor as you configure your champion
- **🔐 Auth Flow** — Register/Login with localStorage (no backend needed)
- **📈 Results Dashboard** — Portfolio timeline chart, best/worst moments, AI market analysis, full event log
- **⌨️ Full Controls** — ↑ Jump · → Dash forward · ↓ Duck · ← Brake

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm

### Install & Run

```bash
# Install dependencies
npm install

# Start dev server
ulimit -n 65536 && npm run dev -- -p 3001
```

Open [http://localhost:3001](http://localhost:3001)

> **Note:** The `ulimit` command is needed on macOS to prevent "too many open files" warnings from the Next.js file watcher.

### Claude AI (Optional)

Create a `.env.local` file in the project root:

```env
ANTHROPIC_API_KEY=sk-ant-YOUR_KEY_HERE
```

Without this key, the game still works fully — it falls back to template story choices. With a real key, every market event generates unique, contextual choices via Claude 3.5 Haiku.

## 🎮 Game Controls

| Key | Action |
|-----|--------|
| ↑ / W / Space | Jump over obstacles |
| → / D | Dash forward (skip ~80px) |
| ↓ / S | Duck (lower hitbox) |
| ← / A | Brake / slow down |
| 1 / 2 / 3 | Pick story choice |

## 🏦 Stock Data

26 stocks across 4 sectors, each with: `ticker`, `company`, `sector`, `risk`, `price`, `returnRate`, `volatility`, `beta`, `dividendYield`, `peRatio`, `marketCap`, `description`

The game course is seeded deterministically from each stock's data — volatility drives obstacle frequency, dividendYield drives chest frequency.
