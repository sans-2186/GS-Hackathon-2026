## 🎮 What is StockQuest?

StockQuest is a forest-adventure stock portfolio game designed for non-finance beginners. Players pick a real stock as their avatar, race through a dynamic forest course, dodge market risks, collect opportunity chests, and make live investment decisions powered by Claude AI — all while learning how real markets work.

Every obstacle is a financial scenario. Every chest is an opportunity. Every choice has a consequence.

```
  → /home (Portfolio Dashboard) → /setup (Pick Your Stock Champion)
    → /game (Forest Race!) → /results (Advisor + Recap)
```

## ✨ Features

### 🌱 Guided Goal-Setting (Onboarding)
- 4-step jargon-free questionnaire capturing investment goal, time horizon, loss reaction, and risk comfort
- Stored in Zustand with `localStorage` persistence
- New users are routed here automatically after registration

### 📊 Portfolio Health Dashboard (Home)
- **Health Score Ring** — 0–100 score showing how balanced and crash-resistant the suggested portfolio is
- **Stat Flashcards** — Portfolio Health, Risk Level, Expected Annual Return, Crash Resilience — all with hover definitions
- **Color-coded Sector Allocation Bar** — visual breakdown of Tech / Finance / Energy / Manufacturing weights
- **AI Suggestions** — rule-based tips for diversification, risk reduction, and rebalancing, each with a "Why This?" transparency panel
- **Portfolio value pill** — shows starting investment at a glance
- **Real Sector Performance Chart** — 12-month normalized price curves (Jun 2025 – May 2026) from actual stock data, not simulated

### 🔍 Hover Definitions
- Every financial term across the dashboard, setup page, and avatar card has a hover tooltip
- Definitions from a centralized jargon-free glossary (`lib/glossary.ts`)
- Tooltips render via `ReactDOM.createPortal` to always appear above all overlays

### 🎮 Forest Runner Game
- 2-minute endless runner on an 1100×550 HTML Canvas
- Parallax layered forest backgrounds, animated trees, clouds, sun
- **Obstacles** → trigger What-If scenarios (market crash, inflation) — negative events requiring portfolio decisions
- **Treasure Chests** → opportunity events (take profits / hold / reinvest)
- Controls: ↑ Jump · → Dash · ↓ Duck · ← Brake · 1/2/3 pick choice
- **Race Complete overlay** — shown for 1.2 seconds before redirecting to results

### 🧠 What-If Scenario Engine (Mid-Game)
- 3 mid-race pauses triggered by collisions, each with a distinct financial scenario
- **Obstacle 1** → Market drops 20% — Hold / Rebalance / Buy the dip
- **Obstacle 2** → Inflation surging — Shift to energy / Hold / Raise cash
- **Chests** → Opportunity: Take profits / Hold for gains / Reinvest
- Choices generated by Claude 3.5 Haiku (falls back to templates if unavailable)
- Each scenario shown with a header card and multiplier impact on portfolio value

### 🏆 Results & Portfolio Advisor
- Final value, gain/loss, obstacle/chest count
- Portfolio timeline chart (Recharts area chart)
- Best moment & hardest obstacle highlight
- **AI Market Analysis** — templated narrative summary of the race
- **Portfolio Advisor** — post-game rebalancing advice based on the user's goal, with a numbered action plan and health score projection
- **Transparency Panel** — plain-language reasoning: why this advice, trade-off to know, goal alignment

### 🤖 Forest Guide Chatbot (Home Page)
- Floating 🌲 button at bottom-right of the home page
- Claude-powered help desk with portfolio context injected into every message
- 4 suggested questions on first open
- Typing indicator, message history, Enter-to-send
- No markdown formatting — conversational plain-text replies
- Falls back to helpful canned tips if Claude is unavailable

### 🔐 Auth & State
- Register / Login with `localStorage` (no backend required)
- Zustand store with `persist` for user, profile, selected stock, game events, result timeline
- Hydration-safe: `mounted` guard prevents server/client mismatch

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm

### Install & Run

```bash
npm install
ulimit -n 65536 && npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

> **macOS note:** The `ulimit` command raises the file descriptor limit to prevent "too many open files" errors from the Next.js watcher.

### Claude AI Setup

Create a `.env.local` file in the project root:

```env
ANTHROPIC_API_KEY=sk-ant-YOUR_KEY_HERE
```

Without a key the game runs fully on template choices and canned chatbot responses. With a real key, every mid-game scenario and chatbot reply is generated by Claude 3.5 Haiku.

| ↑ / W / Space | Jump over obstacles |
| → / D | Dash forward |

| ← / A | Brake / slow down |
